# 🪐 Il Cosmicologo - AV Edition

Un gestore di database personale per catalogare film, pensato per essere leggero, veloce e interamente locale.

## Funzionalità
- 💾 **Salvataggio Locale**: I dati risiedono nel browser.
- 🏷️ **Sistema Alias**: Gestione avanzata dei nomi performer.
- 📊 **Statistiche**: Visualizzazione rapida di Studio, Attrici e Generi.
- 📁 **Import/Export**: Supporto per JSON, CSV e TXT.
- 🌙 **Dark Mode**: Interfaccia ottimizzata.

## Come usarlo
1. Apri `index.html` nel tuo browser preferito.
2. Usa il pannello per aggiungere i film.
3. Effettua regolarmente il backup in formato JSON!
